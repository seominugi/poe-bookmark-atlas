# POE 북마크 아틀라스 — 소개 영상 대본

- **목표 길이**: 3분 30초 ~ 4분 30초
- **구성**: 오프닝 훅 → 확장 소개 → 핵심 기능 데모 → 피드백 업데이트 스토리 → 마무리
- **형식**: 거래소 화면 녹화 + 내레이션. 각 장면은 🎬(화면) / 🎙(대사)로 구분
- **기준 버전**: 0.3.0 (PoB 복사·환산 칩·패널 좌/우는 0.3.0 기능 — 부록 ⚠️ 참조)

---

## 1. 오프닝 훅 (0:00 – 0:15)

🎬 거래소에서 능력치 필터를 하나하나 추가하며 검색을 조립하는 화면. 약간 배속을 걸어 "번거로움"이 느껴지게.

🎙
> 거래소에서 아이템 하나 찾으려고 필터를 조립합니다. 능력치 넣고, 수치 맞추고, 그룹 만들고…
> 그런데 내일, 똑같은 검색을 처음부터 다시 만들고 있지는 않으신가요?

---

## 2. 확장 소개 (0:15 – 0:40)

🎬 크롬 웹스토어 "POE 북마크 아틀라스" 페이지 → 설치 클릭 → 거래소 접속, 우측에서 패널이 슬라이드 인.

🎙
> POE 북마크 아틀라스는, Path of Exile 거래소 검색을 저장해 두고 언제든 클릭 한 번으로 다시 여는 크롬 확장 프로그램입니다.
> POE1과 POE2, 카카오 거래소를 모두 지원합니다.

---

## 3. 핵심 기능 데모 (0:40 – 2:00)

### 3-1. 검색 저장 → 다시 열기 (핵심 루프)

🎬 검색을 하나 완성 → `Alt+S` → 이름 입력, 폴더 선택, 저장. 이후 전혀 다른 검색을 하다가 → 패널에서 북마크 클릭 → 저장했던 검색이 그대로 복원.

🎙
> 원하는 검색을 만들었으면 Alt+S. 이름을 붙여서 폴더에 저장합니다.
> 다음부터는 클릭 한 번이면, 이 검색이 조건 그대로 다시 열립니다.

### 3-2. 조건 칩 + 가격 스냅샷

🎬 북마크 카드 클로즈업 — 조건 칩에 마우스 오버(툴팁으로 전체 조건), 가격에 마우스 오버(검색 시점·매물 수·빠른 판매가 툴팁).

🎙
> 카드만 봐도 뭘 검색했는지 조건이 칩으로 보이고, 저장할 때의 시세도 함께 기록됩니다.
> 가격에 마우스를 올리면 — 검색한 시점, 매물 수, 그리고 빠르게 팔리는 가격대까지 보여줍니다.

### 3-3. 검색 히스토리

🎬 히스토리 섹션 — 자동으로 쌓인 최근 검색들 → 하나를 북마크로 승격하는 장면.

🎙
> 저장을 깜빡해도 괜찮습니다. 검색 히스토리가 자동으로 남고, 마음에 들면 그 자리에서 북마크로 승격시키면 됩니다.

### 3-4. 단축키 + 가이드 투어

🎬 `Alt+B`로 패널 접었다 펴기 → `Alt+A` 능력치 필터 추가 → `Alt+F` 검색 포커스. 이어서 가이드 투어 스포트라이트가 기능을 짚어주는 장면 한 컷.

🎙
> 패널 열기 Alt+B, 능력치 필터 추가 Alt+A처럼 자주 쓰는 동작은 전부 단축키로 할 수 있습니다.
> 외울 필요는 없습니다. 처음 설치하면 가이드 투어가 기능을 하나씩 직접 짚어드립니다.

---

## 4. 피드백 업데이트 스토리 (2:00 – 3:25)

### 전환 멘트

🎬 (화면 전환 — 버전 히스토리나 디스코드 피드백 채널을 슬쩍 보여줘도 좋음)

🎙
> 여기까지가 기본 기능이고요. 감사하게도 출시 이후에 유저분들이 피드백을 보내주셨습니다.
> 받은 피드백을 어떻게 업데이트했는지 보여드릴게요.

### 4-1. 피드백 ① — 비슷한 검색 저장이 막혀요

🎬 수치만 살짝 바꾼 검색을 `Alt+S`로 저장 → "비슷한 북마크가 있습니다" 팝오버 → **취소 / 새로 만들기 / 덮어쓰기** 3지선다 → 덮어쓰기 선택.

🎙
> 첫 번째. 수치만 살짝 바꾼 검색을 저장하려고 하면, 이미 저장된 검색이라며 막히는 문제가 있었습니다.
> 이제는 비슷한 북마크를 발견하면 물어봅니다. 새로 만들지, 덮어쓸지, 취소할지 — 직접 선택하시면 됩니다.

### 4-2. 피드백 ② — 패널을 왼쪽에 두고 싶어요

🎬 푸터의 설정 → 패널 위치 "왼쪽" 선택 → 패널이 왼쪽으로 이동.

🎙
> 두 번째. 패널이 오른쪽에 고정이라 불편하다는 의견이 있었습니다.
> 설정에서 왼쪽, 오른쪽 — 원하는 자리에 두시면 됩니다.

### 4-3. 피드백 ③ — 아이템을 PoB에 넣고 싶어요 (메인 꼭지)

🎬 검색 결과 아이템 카드의 **PoB / 영문 복사** 버튼 클릭 → "복사됨" → Path of Building을 띄우고 Ctrl+V → 아이템이 영문으로 들어가는 장면. (POE1·POE2 각각 한 컷이면 베스트)

🎙
> 세 번째, 이번 업데이트에서 가장 큰 기능입니다.
> 한국 거래소 아이템은 한글이라서, Path of Building에 붙여넣을 수가 없었죠.
> 이제 아이템 옆의 PoB 버튼을 누르면 영문으로 번역된 텍스트가 복사되고, PoB에 그대로 붙여넣으면 됩니다. POE1, POE2 둘 다 지원합니다.

🎬 번역 안 된 줄이 있는 아이템에서 PoB 버튼 **Shift+클릭** → 제보 텍스트 복사 + 디스코드 초대가 새 탭으로 열리는 장면.

🎙
> 다만 번역이 아직 100% 완벽하지는 않습니다.
> 그래서 번역이 안 된 줄이 보이면, 버튼을 Shift+클릭해 주세요. 제보 내용이 자동으로 복사되고 디스코드가 열립니다.
> 제보해 주시는 만큼, 번역은 점점 정확해집니다.

### 4-4. 그 외 개선 (빠른 컷 모음)

🎬 ① 제시 가격 옆 엑잘/카오스 환산 칩 → ② 새 히스토리 카드(조건 칩 + ⋯ 메뉴) → ③ 가이드 투어 화살표 연결 + ← → 방향키 이동. 컷당 3~4초.

🎙
> 그 외에도 — 제시 가격 옆에 엑잘티드, POE1은 카오스 환산값이 자동으로 붙고요.
> 히스토리 카드도 북마크와 같은 모양으로 새로 다듬었고, 가이드 투어는 화살표 연결과 방향키 이동으로 더 편해졌습니다.

## 5. 마무리 (3:25 – 3:50)

🎬 패널 전체가 보이는 안정된 샷 → 스토어 검색 화면("POE 북마크 아틀라스") → 디스코드 링크 자막.

🎙
> 오늘 보여드린 업데이트 대부분이, 실제 유저분들의 피드백에서 나왔습니다.
> 앞으로도 이렇게 피드백을 받으면서, 함께 사용하기 좋은 확장 프로그램으로 개선해 나가고 싶습니다.
> 설치 링크와 디스코드는 설명란에 남겨둘게요. 거래소 생활이 조금 편해지셨으면 좋겠습니다. 감사합니다.
