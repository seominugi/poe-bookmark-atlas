# POE 북마크 아틀라스 — 소개 영상 대본

이 문서에는 **두 버전**이 들어 있다. 촬영할 것을 고르고, 나머지는 참고용으로 둔다.

| 버전 | 길이 | 용도 |
|---|---|---|
| **A. 짧은 버전** (본편) | 약 2분 | 스토어·커뮤니티 첫 노출. 핵심 루프 + 대표 기능 2개 |
| **B. 전체 소개 버전** | 약 4분 | 기능을 전부 훑는 상세판. A로 유입된 사람이 더 볼 것 |

공통 전제

- **형식**: 거래소 화면 녹화 + 내레이션. 각 장면은 🎬(화면) / 🎙(대사)로 구분
- **기준 버전**: 0.6.6
- **지원 범위 문구 주의**: 두 버전 모두 **카카오 거래소(POE1 `/trade` · POE2 `/trade2`)** 만 지원 대상으로 말한다. 글로벌 `pathofexile.com`은 선택 권한이고 봇 챌린지 이슈가 있으며 `/trade2`에는 패널이 붙지 않는다 — 영상에서 지원한다고 단언하지 않는다.

# A. 짧은 버전 (약 2분) — 본편

**압축 원칙**: 재현이 쉽고 설명이 필요 없는 것만 남긴다. 「고통 하나 → 해소 하나」를 세 번 반복하고 끝낸다.
**뺀 것과 사유**: 리그 이관(끝난 리그 북마크가 있어야 촬영 가능) · 찜 상태 확인('팔림' 재현에 하루 필요) · 히스토리·폴더·단축키·설정(설명 비용 대비 임팩트 낮음). 전부 B 버전에 있다.

## A-1. 훅 (0:00 – 0:12)

🎬 거래소에서 능력치 필터를 하나하나 조립하는 화면. 드롭다운 → 타이핑 → 선택 → 수치 입력을 대여섯 번 반복. 배속을 걸어 지루함이 느껴지게.

🎙
> 거래소에서 아이템 하나 찾으려고 이 짓을 합니다. 그리고 내일 또 합니다.

## A-2. 정체 (0:12 – 0:25)

🎬 패널이 우측에서 슬라이드 인 → 북마크 목록이 보이는 안정된 샷.

🎙
> POE 북마크 아틀라스. 거래소 검색을 저장해 두고 클릭 한 번으로 다시 여는 크롬 확장입니다.
> 카카오 거래소 POE1, POE2에서 쓸 수 있습니다.

## A-3. 핵심 루프 — 저장하고 다시 연다 (0:25 – 0:52)

🎬 방금 조립한 검색에서 `Alt+S` → **이름이 조건에서 자동으로 채워져 있는** 저장 다이얼로그 → 폴더 골라 저장. → 다른 검색을 한 번 하고 → 패널의 북마크 클릭 → 조건 그대로 복원.

🎙
> 검색을 만들었으면 Alt+S. 이름은 조건에서 알아서 채워지니까 폴더만 고르면 됩니다.
> 다음부터는 클릭 한 번. 조건 그대로 다시 열립니다.
> 저장을 깜빡해도 괜찮습니다. 거래소에서 한 검색은 히스토리에 자동으로 쌓입니다.

## A-4. 조건 묶음 — 만드는 것도 줄인다 (0:52 – 1:20)

🎬 좌우 비교로 붙일 것. **왼쪽**: 저항 조건 4개를 손으로 넣는 장면(드롭다운·타이핑·선택·수치 반복, 배속). **오른쪽**: 패널의 조건 묶음 칩 「저항 묶음」을 **한 번 클릭** → 같은 조건이 통째로 얹힘.

🎙
> 저장만 하는 게 아닙니다. 검색을 만드는 것 자체를 줄여줍니다.
> 자주 쓰는 조건 뭉치는 "묶음"으로 저장해 두고, 칩 한 번이면 지금 검색 위에 통째로 얹힙니다.
> 가격이나 정렬은 그대로 두고 조건만 더해집니다.

## A-5. PoB 영문 복사 (1:20 – 1:50)

🎬 검색 결과 아이템 카드의 **`PoB` 버튼** 클릭 → "복사됨" → Path of Building으로 전환해 `Ctrl+V` → 한글 아이템이 영문으로 들어가 **스탯이 실제로 계산되는** 장면.

> 💡 이 컷에 **환산 칩**을 인서트로 끼울 것 — 아이템 카드를 잡을 때 제시 가격 옆 환산값이 자연스럽게 화면에 들어오게 구도를 잡으면 대사 한 줄로 끝난다.

🎙
> 그리고 한국 거래소 아이템은 한글이라, Path of Building에 그대로 붙여넣을 수가 없었죠.
> PoB 버튼을 누르면 영문으로 번역돼 복사됩니다. 붙여넣으면 그대로 들어갑니다. POE1, POE2 둘 다요.
> 가격 옆에 카오스·신성한 환산값이 붙는 것도 보이실 겁니다.

## A-6. 마무리 (1:50 – 2:05)

🎬 패널 전체 샷 → 스토어 검색 화면("POE 북마크 아틀라스") → 디스코드 링크 자막.

🎙
> 이 기능들 대부분이 유저분들 피드백에서 나왔습니다. 앞으로도 그렇게 고쳐 나가려고 합니다.
> 설치 링크와 디스코드는 설명란에 있습니다. 감사합니다.

## A-부록. 짧은 버전 촬영 체크리스트

B 버전보다 준비물이 훨씬 적다. **끝난 리그 북마크도, 묵혀둔 찜 매물도 필요 없다.**

- [ ] 데모용 북마크·폴더 몇 개 미리 채워두기 (빈 패널 방지)
- [ ] **조건 묶음 1개** 등록 — A-4는 이게 없으면 촬영 불가
- [ ] A-4의 "손으로 넣는" 컷과 "칩 한 번" 컷이 **같은 조건**이어야 비교가 성립. 어떤 조건 4개인지 미리 정해둘 것
- [ ] **PoB 붙여넣기 리허설** — poe1·poe2 각 1회 실제 import 확인
- [ ] A-5 구도에 **환산 칩이 화면에 들어오는지** 미리 확인 (안 들어오면 대사 마지막 줄을 뺀다)
- [ ] 녹화 해상도에서 조건 칩·환산 칩 가독성 확인 (필요하면 클로즈업 인서트)
- [ ] 개인정보: 계정명·POESESSID·캐릭터명 노출 확인
- [ ] 촬영 시점 스토어 게시 버전이 0.6.6 이상인지 확인

# B. 전체 소개 버전 (약 4분)

- **목표 길이**: 3분 30초 ~ 4분 30초 (아래 타임코드는 약 4분 기준)
- **구성**: 오프닝 훅 → 소개 → 핵심 루프 → 고통 ①조립 ②리그 ③매물 → 마무리

## 1. 오프닝 훅 (0:00 – 0:15)

🎬 거래소에서 능력치 필터를 하나하나 추가하며 검색을 조립하는 화면. 드롭다운 열고 → 타이핑하고 → 고르고 → 수치 넣고, 이 반복을 대여섯 번. 약간 배속을 걸어 "번거로움"이 느껴지게.

🎙
> 거래소에서 아이템 하나 찾으려고 필터를 조립합니다. 능력치 넣고, 수치 맞추고, 그룹 만들고…
> 그런데 내일, 똑같은 검색을 처음부터 다시 만들고 있지는 않으신가요?

---

## 2. 확장 소개 (0:15 – 0:35)

🎬 크롬 웹스토어 "POE 북마크 아틀라스" 페이지 → 설치 클릭 → 거래소 접속, 우측에서 패널이 슬라이드 인.

🎙
> POE 북마크 아틀라스는, 거래소 검색을 저장해 두고 언제든 클릭 한 번으로 다시 여는 크롬 확장 프로그램입니다.
> 카카오 거래소의 POE1, POE2 양쪽에서 쓸 수 있습니다.

---

## 3. 핵심 루프 — 저장하고, 다시 연다 (0:35 – 1:15)

### 3-1. 저장 → 복원

🎬 검색을 하나 완성 → `Alt+S` → 저장 다이얼로그에 **이름이 조건에서 자동으로 채워져 있는 것**을 보여주고, 폴더를 골라 저장. 이후 전혀 다른 검색을 두어 번 하다가 → 패널에서 북마크 클릭 → 저장했던 검색이 조건 그대로 복원.

🎙
> 원하는 검색을 만들었으면 Alt+S. 이름은 검색 조건에서 알아서 채워지니까, 폴더만 골라서 저장하면 됩니다.
> 다음부터는 클릭 한 번이면, 이 검색이 조건 그대로 다시 열립니다.

### 3-2. 저장을 깜빡해도 — 히스토리

🎬 히스토리 섹션 — 자동으로 쌓인 최근 검색들 → 그중 하나의 **☆를 눌러 북마크로 승격**되는 장면.

🎙
> 저장을 깜빡해도 괜찮습니다. 거래소에서 검색하면 히스토리에 자동으로 쌓이고, 마음에 들면 별표 한 번으로 북마크로 올리면 됩니다.

### 3-3. 폴더로 정리

🎬 폴더 색상 변경(아이콘 클릭) 한 컷 → 폴더 헤더의 **`+ 이 폴더에 현재 검색 저장`** 클릭 한 컷. 짧게.

🎙
> 폴더는 색으로 구분해 두면 찾기 편하고, 폴더 위의 플러스를 누르면 지금 검색을 그 폴더로 곧장 넣습니다.

---

## 4. 고통 ① — 검색 조립이 매번 귀찮다 (1:15 – 2:00)

### 전환 멘트

🎙
> 그런데 이 확장이 하는 일은 "저장"만이 아닙니다. 애초에 **검색을 만드는 것 자체**를 줄여줍니다.

### 4-1. 조건 묶음 — 클릭 1회로 조건 얹기 (메인 꼭지)

🎬 ① 먼저 **거래소에서 손으로** 저항 조건 3~4개를 넣는 장면을 짧게 배속 (드롭다운 → 타이핑 → 선택 → 수치, 반복) → ② 화면 전환 → 패널 상단의 **조건 묶음 칩 「저항 묶음」을 한 번 클릭** → 같은 조건이 통째로 현재 검색에 얹히는 장면. ③ 이어서 북마크 카드 `⋯` → **`조건 묶음으로 등록`** 으로 묶음을 만드는 방법 한 컷.

🎙
> 자주 쓰는 조건 뭉치는 "묶음"으로 저장해 둘 수 있습니다.
> 손으로 넣으면 조건 하나마다 드롭다운, 타이핑, 선택, 수치 입력이 반복되는데 — 묶음은 칩 한 번 클릭이면 끝입니다.
> 가격이나 정렬은 건드리지 않고, 조건만 더해집니다. 묶음은 북마크 카드의 점 세 개 메뉴에서 바로 만들 수 있습니다.

🎬 (여유 있으면) 칩을 **드래그해 순서를 바꾸는** 컷 + 묶음 줄을 **접어서** 목록 공간을 넓히는 컷. 각 2초.

🎙
> 자주 쓰는 묶음은 앞으로 끌어다 두고, 안 쓸 땐 접어두면 됩니다.

### 4-2. 조건 칩 — 조건 하나만 빌리기

🎬 북마크 카드의 **`조건 N개` 칩에 마우스 오버**(툴팁으로 어떤 조건인지 미리보기) → 클릭 → 그 검색의 능력치가 현재 검색에 더해지는 장면.

🎙
> 묶음으로 등록할 정도는 아니고, 저 북마크의 조건만 빌려오고 싶을 때가 있죠.
> 카드의 "조건" 칩을 누르면 그 검색의 능력치가 지금 검색에 더해집니다. 마우스만 올려도 뭐가 들었는지 미리 보입니다.

### 4-3. 단축키

🎬 `Alt+A` 능력치 필터 추가 → **한 번 더 눌러 다른 그룹으로 순환**되는 것 → `Alt+G` 그룹 추가 → `Alt+F` 아이템 검색 포커스 → `Alt+K` 패널 검색창 포커스. 빠르게 이어서.

🎙
> 손이 마우스를 떠나지 않게 단축키도 있습니다. Alt+A로 능력치 필터 추가, 한 번 더 누르면 다른 그룹으로 넘어가고요.
> Alt+G는 그룹 추가, Alt+F는 아이템 검색, Alt+K는 패널에서 북마크 찾기입니다.
> 외울 필요는 없습니다. 패널 아래 키보드 칩에 마우스만 올리면 전부 정리돼 뜨고, 처음 설치하면 가이드 투어가 하나씩 직접 짚어드립니다.

## 5. 고통 ② — 리그가 바뀌면 북마크가 다 죽는다 (2:00 – 2:35)

🎬 **끝난 리그**에 저장해 둔 북마크 카드 — 카드에 **`🏆 내 리그로 다시 검색`** 액션이 이미 떠 있는 상태(메뉴를 열 필요 없음) → 클릭 → 같은 조건 그대로 현재 리그에서 검색되는 장면. 이어서 설정에서 **'내 리그'를 지정**하는 컷.

> ⚠ **이 액션은 저장 당시 리그가 「이미 끝난 리그」일 때만 뜬다.** 스탠다드↔하드코어처럼 둘 다 열려 있는 경우엔 안 깨진 것으로 보고 표시하지 않는다 (`renderList.js:373`). 촬영용 북마크는 반드시 **종료된 과거 리그**에서 저장한 것이어야 한다.

🎙
> 북마크를 오래 쓰면 결국 리그가 끝납니다. 지난 리그에 저장한 검색은 그대로는 안 열리죠.
> 그럴 땐 카드에 "내 리그로 다시 검색"이 떠 있습니다. 한 번 누르면 조건은 그대로 두고 리그만 지금 리그로 옮겨서 다시 찾아줍니다.
> 어느 리그를 쓰는지는 설정에서 지정해 두면 됩니다.

🎬 북마크의 **가격에 마우스 오버** — 검색 시점, 매물 수, 빠르게 팔리는 가격대 툴팁 → 북마크를 열자 **최신 시세로 갱신**되는 장면.

🎙
> 가격도 마찬가지입니다. 저장할 때의 시세가 함께 기록돼서, 마우스만 올리면 그때 매물이 얼마였는지 보이고요.
> 북마크를 열면 지금 시세로 갱신됩니다. 이 아이템이 그동안 올랐는지 내렸는지 그냥 보입니다.

## 6. 고통 ③ — 매물을 만난 다음이 진짜 문제다 (2:35 – 3:35)

### 전환 멘트

🎙
> 검색을 잘 만들어서 좋은 매물을 찾았습니다. 그다음이 문제죠.

### 6-1. 환산 칩

🎬 검색 결과 목록 — 제시 가격 옆에 **환산 칩이 자동으로 붙어 있는** 클로즈업. 카오스로 표시된 매물 옆 신성한 환산, 신성한으로 표시된 매물 옆 카오스 환산이 **양쪽 다** 붙는 걸 보여줄 것.

🎙
> 매물마다 화폐가 달라서 비싼지 싼지 감이 안 올 때가 있죠.
> 제시 가격 옆에 환산값이 자동으로 붙습니다. 카오스로 올라온 건 신성한으로, 신성한으로 올라온 건 카오스로 — 양방향입니다. 서미누기 환율 기준이고요.

### 6-2. 찜한 매물 + 생존 확인

🎬 마음에 드는 매물 카드의 **★ 클릭** → 패널 **「찜한 매물」** 섹션에 썸네일과 함께 쌓이는 장면 → 시간이 지난 뒤 **`상태 확인`** 버튼 클릭 → 아직 살아 있는 매물과 팔린 매물이 구분되는 장면.

🎙
> 지금 당장 살 게 아니라면 별표로 찜해 두세요. 패널에 따로 모입니다.
> 나중에 "상태 확인"을 누르면, 이 매물이 아직 있는지 거래소에 직접 확인해 줍니다. 팔린 매물을 붙잡고 있을 필요가 없어졌습니다.

### 6-3. PoB 영문 복사 (클라이맥스)

🎬 아이템 카드의 **`PoB` 버튼** 클릭 → "복사됨" → Path of Building으로 전환해 `Ctrl+V` → 한글 아이템이 **영문으로 들어가서 스탯이 실제로 계산되는** 장면. POE1·POE2 각각 한 컷이면 베스트.

🎙
> 그리고 이번 확장에서 가장 손이 많이 간 기능입니다.
> 한국 거래소 아이템은 한글이라서, Path of Building에 그대로 붙여넣을 수가 없었죠.
> 이제 아이템 옆의 PoB 버튼을 누르면 영문으로 번역된 import 텍스트가 복사됩니다. PoB에 붙여넣으면 그대로 들어갑니다. 품질, 소켓, 영향력까지 같이 넘어갑니다.

🎬 번역 안 된 줄이 남아 있는 아이템에서 PoB 버튼 **Shift+클릭** → 제보 텍스트 복사 + 디스코드 초대가 새 탭으로 열리는 장면.

🎙
> 다만 번역이 아직 100% 완벽하지는 않습니다.
> 번역이 안 된 줄이 보이면 버튼을 Shift+클릭해 주세요. 제보 내용이 자동으로 복사되고 디스코드가 열립니다.
> 실제로 제보 하나가 올라올 때마다 사전을 고쳐 왔습니다. 제보해 주시는 만큼 정확해집니다.

## 부록 A — 촬영 준비 체크리스트 (B 전체 버전용)

> 짧은 버전만 찍는다면 위쪽 **A-부록**의 짧은 체크리스트를 쓴다. 준비물이 훨씬 적다.

### 데이터 준비

- [ ] 데모용 북마크·폴더·히스토리 미리 채워두기 (빈 화면 방지). 폴더는 **색을 다르게** 최소 3개 — 3-3 컷에 필요
- [ ] **조건 묶음 최소 2개** 등록해 둘 것 (4-1의 클릭 데모 + 드래그 재배치 컷에 2개 이상 필요)
- [ ] **끝난 리그의 북마크 1개** — 5장 "내 리그로 다시 검색" 데모용. **현재 열려 있는 다른 리그(스탠다드·하드코어)에 저장한 건 액션이 안 뜬다.** 반드시 종료된 과거 리그에 저장한 북마크여야 하며, 없으면 이 컷은 재현 불가하니 미리 확보
- [ ] 설정에서 **'내 리그'가 지정된 상태** 확인 (미지정이면 5장 흐름이 어색해짐)
- [ ] 가격 스냅샷이 실제로 붙은 북마크 1개 (저장 후 시간이 좀 지난 것 — 갱신 전후 차이가 보여야 함)

### 재현이 까다로운 컷 (미리 리허설 필수)

- [ ] **찜 「상태 확인」의 '팔림' 결과** — 이게 제일 어렵다. 팔릴 만한 저가 매물을 미리 여러 개 찜해 두고 하루쯤 묵혀야 '사라진 매물'이 나온다. 안 되면 살아 있는 매물만 확인되는 컷으로 대체하고 내레이션을 "아직 있는지 확인해 줍니다"까지만 말할 것
- [ ] **찜 확인은 "지금 보고 있는 거래소"의 매물만 조회한다** — POE1에서 찜한 걸 POE2 페이지에서 "상태 확인" 눌러도 안 잡힌다. 찜한 게임과 촬영 중인 탭을 맞출 것
- [ ] **PoB 붙여넣기** — poe1·poe2 각 1회 실제 import 리허설. 품질·소켓·영향력이 붙은 아이템으로 (내레이션에서 언급함)
- [ ] **Shift+클릭 제보** — 번역이 실제로 빠지는 아이템 1개 확보. 사전이 많이 채워져서 찾기 어려울 수 있음
- [ ] **Alt+A 그룹 순환** — 능력치 그룹이 2개 이상인 검색에서만 순환이 보인다. 그룹 2개짜리 검색 준비

### 촬영 환경

- [ ] 녹화 해상도에서 패널 폰트 가독성 확인 (조건 칩·툴팁·환산 칩이 작게 보일 수 있음 — 필요하면 클로즈업/줌 인서트)
- [ ] 개인정보: 계정명·POESESSID·캐릭터명이 화면에 노출되지 않는지 확인
- [ ] 버전 확인: 촬영 시점 스토어 게시 버전이 대본 기준(0.6.6) 이상인지. 스토어보다 앞선 기능을 보여주면 "내 건 왜 없냐" 문의가 온다
